# CareerChain

CareerChain is a collaborative web platform designed for university students, alumni, and administrators to connect, share job opportunities, seek mentorship, and accelerate career development.

## Key Features
- **Role-based Authentication**: Distinct access for Students, Alumni, and Administrators.
- **Job & Internship Board**: Real-time opportunity posting and matching.
- **Mentorship & Alumni Directory**: Connect with industry professionals.
- **Community Feed**: Interactive updates, discussions, and event sharing.
- **AI Career Assistant**: Resume parsing and career guidance tools.

## Architecture
- **Backend**: FastAPI with SQLite/MySQL and Pydantic schemas.
- **Frontend**: React (Vite) styled with Tailwind CSS.
